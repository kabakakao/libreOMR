# Public-domain sample score

`bach-bwv1013.pdf` contains Johann Sebastian Bach's **Partita in A minor for solo
flute, BWV 1013**. The unmodified PDF comes from the Mutopia Project:

- [Work page and rights notice](https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=1528)
- [Original A4 PDF](https://www.mutopiaproject.org/ftp/BachJS/BWV1013/bwv1013/bwv1013-a4.pdf)
- Typeset by Jacob Shapiro using LilyPond.
- Edition: Mutopia-2017/10/31-1528.
- Source rights notice: **Public Domain**. The typesetter also released the
  typesetting into the public domain; the notice appears on the first PDF page.
- Source and rights notice checked on October 22, 2026.

SHA-256 of the unmodified download:
`f73c6e478af78237ebf0cf2e9842cf111937e76e6e5e018bb85e5be729a31d47`.

Open the file in libreOMR with **File > Open image**. It serves as a public
example and as the source for the project README screenshots. The screenshots
show the first page (Allemande). Recognition proposals are not a reviewed
transcription.
