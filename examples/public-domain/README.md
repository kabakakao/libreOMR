Soloflöte, BWV 1013**. Das unveränderte PDF stammt aus dem Mutopia Project:

- Rechteangabe der Quelle: **Public Domain**. Auch der Notensatz wurde vom
  Ersteller als gemeinfrei freigegeben; der Hinweis steht auf der ersten PDF-Seite.
- Quelle und Rechteangabe geprüft am 22. Oktober 2026.
