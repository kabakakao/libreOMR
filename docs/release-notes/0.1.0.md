Erste Version von **libreOMR**, einer Desktop-Anwendung zur lokalen optischen
Notenerkennung für Linux, Windows und macOS.

libreOMR 0.1.0 ist ein **früher Prototyp**. Die Erkennung verwendet Heuristiken
und Symbolvorlagen; Ergebnisse müssen musikalisch geprüft und korrigiert werden.

## Funktionen

- Import von PDF, PNG, JPEG, TIFF und BMP, einschließlich mehrseitiger PDFs und TIFFs.
- Erkennung und Bearbeitung von Noten, Pausen, Schlüsseln, Vorzeichen und Taktangaben
  sowie weiteren musikalischen Symbolen.
- Direkter Vergleich von Originalbild, Erkennungsvorschlägen und Notenvorschau.
- Korrekturwerkzeuge mit Undo/Redo und Projektdateien mit eingebetteten Notenbildern.
- Export aller Seiten als MusicXML 4.0 zur Weiterarbeit in einem Notensatzprogramm.
- Helles und dunkles Design sowie ein gemeinfreies Bach-Beispiel zum Ausprobieren.
- Vollständige lokale Verarbeitung der Notenbilder.

## Downloads und Start

Das passende Archiv vollständig entpacken:

| Plattform | Archiv | Anwendung |
| --- | --- | --- |
| Linux x86_64 | `libreomr-0.1.0-x86_64-unknown-linux-gnu.tar.gz` | `libreomr` |
| Windows x86_64 | `libreomr-0.1.0-x86_64-pc-windows-msvc.zip` | `libreomr.exe` |
| Windows ARM64 | `libreomr-0.1.0-aarch64-pc-windows-msvc.zip` | `libreomr.exe` |
| macOS Apple Silicon | `libreomr-0.1.0-aarch64-apple-darwin.zip` | `libreOMR.app` |

Jedes Binärpaket enthält außerdem das Benchmark-Programm `omr-benchmark`,
die Nutzungsanleitung, die öffentliche Beispielpartitur und Lizenzhinweise.
`SHA256SUMS` enthält die SHA-256-Prüfsummen der Release-Archive.

Unter Linux werden eine grafische X11- oder Wayland-Sitzung sowie die
Systembibliotheken für XKB, Wayland und EGL benötigt. Für den Dateidialog
muss `xdg-desktop-portal` mit einem passenden Desktop-Backend verfügbar sein.
Die Linux-Pakete werden auf Ubuntu 22.04 gebaut und bündeln diese
Systembibliotheken nicht.

Die macOS-App ist nicht signiert oder notarisiert. Beim ersten Start kann eine
Freigabe unter **Systemeinstellungen > Datenschutz & Sicherheit** erforderlich
sein. Intel-Macs werden nicht unterstützt.

## Quellcode und Lizenz

libreOMR steht unter **GPL-3.0-or-later**. Das zusätzliche Archiv
`libreomr-0.1.0-source.tar.gz` enthält den zugehörigen Quellcode und die durch
`Cargo.lock` fixierten Cargo-Abhängigkeiten. Mit Rust ab Version 1.92 und den
Systembibliotheken lässt es sich offline bauen:

```sh
cargo build --release --locked --offline
```

Weitere Hinweise zu Installation und Bedienung stehen in der mitgelieferten
README. Fonts und Beispielpartitur behalten ihre eigenen Lizenz- bzw.
Gemeinfreiheitsangaben.
