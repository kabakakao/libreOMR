The first version of **libreOMR**, a desktop application for local optical music
recognition on Linux, Windows and macOS.

libreOMR 0.1.0 is an **early prototype**. Recognition uses heuristics and symbol
templates; results require musical review and correction.

## Features

- Import PDF, PNG, JPEG, TIFF and BMP, including multipage PDFs and TIFFs.
- Recognize and edit notes, rests, clefs, accidentals, time signatures and other
  musical symbols.
- Compare the original image, recognition proposals and notation preview directly.
- Correction tools with undo/redo and project files with embedded score images.
- Export all pages as MusicXML 4.0 for further work in a notation program.
- Light and dark appearance and a public-domain Bach example to try.
- Entirely local processing of score images.

## Downloads and startup

Extract the entire archive for your platform:

| Platform | Archive | Application |
| --- | --- | --- |
| Linux x86_64 | `libreomr-0.1.0-x86_64-unknown-linux-gnu.tar.gz` | `libreomr` |
| Windows x86_64 | `libreomr-0.1.0-x86_64-pc-windows-msvc.zip` | `libreomr.exe` |
| Windows ARM64 | `libreomr-0.1.0-aarch64-pc-windows-msvc.zip` | `libreomr.exe` |
| macOS Apple Silicon | `libreomr-0.1.0-aarch64-apple-darwin.zip` | `libreOMR.app` |

Each binary package also contains `omr-benchmark`, the user guide, public sample
score and license notices. `SHA256SUMS` lists SHA-256 checksums of release archives.

Linux requires a graphical X11 or Wayland session and system libraries for XKB,
Wayland and EGL. File dialogs require `xdg-desktop-portal` and a matching desktop
backend. Linux packages are built on Ubuntu 22.04 and do not bundle these libraries.

The macOS app is not signed or notarized. First launch may require approval in
**System Settings > Privacy & Security**. Intel Macs are not supported.

## Source code and license

libreOMR uses **GPL-3.0-or-later**. The additional
`libreomr-0.1.0-source.tar.gz` archive contains corresponding source code and
Cargo dependencies pinned by `Cargo.lock`. With Rust 1.92 or newer and system
libraries installed, it can be built offline:

```sh
cargo build --release --locked --offline
```

See the included README for installation and usage. Fonts and the sample score
retain their own license or public-domain notices.
