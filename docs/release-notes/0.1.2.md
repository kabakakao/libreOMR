**libreOMR 0.1.2** adds English and German interfaces, persistent language and
appearance settings, and a Windows application that starts without a console window.

libreOMR remains an **early prototype** for local optical music recognition.
Recognition results require musical review and correction.

## Changes since 0.1.1

- **English and German:** The interface, musical labels, import messages and
  export diagnostics use embedded JSON language files. The initial language
  follows the system: German for German locales, English for other locales.
- **Settings:** The gear button opens language and appearance preferences.
  Choose System default, English or Deutsch, and Follow system, Light or Dark.
  Changes apply immediately, are saved for the current user and are restored
  at the next launch. Appearance controls now live in Settings.
- **Windows startup:** The desktop executable uses the Windows GUI subsystem,
  so launching it does not open an additional console window. Native error
  dialogs and diagnostic logs remain available. The benchmark remains a
  command-line program.
- **English documentation:** The README, developer documentation, release
  instructions and benchmark documentation are now in English. Binary packages
  include the documentation and localization guide.
- **Updated screenshots:** Four new English captures show the overview,
  correction tools, dark appearance and Settings. Native framebuffer capture
  works with both the Windows wgpu renderer and OpenGL.
- **Regression checks:** Additional checks cover language catalogs, system
  locale resolution, settings persistence, controls at both window sizes and
  the Windows GUI subsystem. A language-switch test verifies that score data
  and exported MusicXML notation stay unchanged.

## Downloads and startup

Extract the entire archive for your platform:

| Platform | Archive | Application |
| --- | --- | --- |
| Windows x86_64 | `libreomr-0.1.2-x86_64-pc-windows-msvc.zip` | `libreomr.exe` |
| Windows ARM64 | `libreomr-0.1.2-aarch64-pc-windows-msvc.zip` | `libreomr.exe` |
| Linux x86_64 | `libreomr-0.1.2-x86_64-unknown-linux-gnu.tar.gz` | `libreomr` |
| macOS Apple Silicon | `libreomr-0.1.2-aarch64-apple-darwin.zip` | `libreOMR.app` |

Each binary package also includes `omr-benchmark`, the user guide, documentation,
public sample score and license notices. `SHA256SUMS` lists the SHA-256 checksums
of all five release archives, including the corresponding source archive.

Linux requires a graphical X11 or Wayland session, system libraries for XKB,
Wayland and EGL, and `xdg-desktop-portal` with a matching desktop backend. Place
the extracted directory in a permanent location and run `python3 install-desktop.py`
inside it to install the application-menu entry for the current user.

On macOS, copy `libreOMR.app` to Applications. The app is not signed or notarized;
first launch may require approval in **System Settings > Privacy & Security**.
Intel Macs are not supported. Windows requires Windows 10/11 and working
Direct3D 12 support; the README describes the Vulkan alternative.

## Source code and license

libreOMR uses **GPL-3.0-or-later**. The additional
`libreomr-0.1.2-source.tar.gz` archive includes corresponding source code and
the Cargo dependencies pinned by `Cargo.lock`. With Rust 1.92 or newer, native
build tools and system libraries installed, build it offline with:

```sh
cargo build --release --locked --offline
```

Fonts and the sample score retain their own license or public-domain notices.
See the included README and `docs/localization.md` for usage and settings details.
