**libreOMR 0.1.1** improves Windows startup, error reporting and application-icon
integration on Windows, macOS and Linux.

libreOMR remains an **early prototype** for local optical music recognition.
Recognition results require musical review and correction.

## Changes since 0.1.0

- **Windows graphics:** The build includes the wgpu renderer and uses Direct3D 12
  by default, removing the previous OpenGL dependency at startup. Windows 10/11
  with working Direct3D 12 support is required. The README describes starting
  with Vulkan as an alternative when a Vulkan driver is available.
- **Visible errors:** Startup errors and Rust panics appear in a native error
  dialog even if the main window could not open. The dialog includes technical
  details and the error-report path, normally `%LOCALAPPDATA%\libreOMR\error.log`
  on Windows, falling back to `%TEMP%\libreOMR\error.log`. Panic reports include
  a stack trace.
- **Windows icon:** The EXE embeds application icons in seven sizes for Explorer
  and shortcuts, including high-resolution displays.
- **macOS icon:** Finder and Dock icons share prepared images with Retina sizes
  up to 1024 pixels. Packaging checks the icon reference and ICNS file.
- **Linux integration:** A desktop entry, application-menu icons and an
  application ID for window association are included. `python3 install-desktop.py`
  installs the menu entry for the current user without administrator privileges.
- **Packaging and checks:** Archives preserve executable permissions for Linux
  and macOS binaries. Additional checks cover icon files, the Linux desktop entry
  and, on Windows, the visible error dialog when graphics support is unavailable.

## Downloads and startup

Extract the entire archive for your platform:

| Platform | Archive | Application |
| --- | --- | --- |
| Windows x86_64 | `libreomr-0.1.1-x86_64-pc-windows-msvc.zip` | `libreomr.exe` |
| Windows ARM64 | `libreomr-0.1.1-aarch64-pc-windows-msvc.zip` | `libreomr.exe` |
| Linux x86_64 | `libreomr-0.1.1-x86_64-unknown-linux-gnu.tar.gz` | `libreomr` |
| macOS Apple Silicon | `libreomr-0.1.1-aarch64-apple-darwin.zip` | `libreOMR.app` |

Each binary package also contains the `omr-benchmark` program, user guide,
public sample score and license notices. `SHA256SUMS` lists the release
archives' SHA-256 checksums.

Linux requires a graphical X11 or Wayland session and the system libraries for
XKB, Wayland and EGL. File dialogs use `xdg-desktop-portal` with a matching
desktop backend. Packages are built on Ubuntu 22.04 and do not bundle these
system libraries.

For the Linux menu entry, put the extracted directory in a permanent location
and run `python3 install-desktop.py` inside it (Python 3 required). The entry
starts the program from this directory. Run the command again after moving it.

On macOS, copy `libreOMR.app` to Applications. The app is not signed or notarized;
first launch may require approval in **System Settings > Privacy & Security**.
Intel Macs are not supported.

## Source code and license

libreOMR uses **GPL-3.0-or-later**. The additional
`libreomr-0.1.1-source.tar.gz` archive contains the corresponding source and
Cargo dependencies pinned by `Cargo.lock`. With Rust 1.92 or newer, native build
tools and system libraries installed, it can be built offline:

```sh
cargo build --release --locked --offline
```

See the included README for installation and usage. Fonts and the sample score
retain their own license or public-domain notices.
